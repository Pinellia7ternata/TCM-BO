## 4. ⚠️ 重要发现：本体当前不是严格 OWL 2 DL

`measure` 报 `owl2_dl = false`、`IllegalPunning = 3,235`。已定位到**唯一成因**。

### 成因

`ICD11ID_data` 被**同时声明**为两种互不兼容的实体类型：

```xml
<!-- 第 106 行 -->
<owl:AnnotationProperty rdf:about="http://OntoTCM.org.cn/ontologies/TCM_TO/ICD11ID_data">
    <rdfs:range rdf:resource="http://www.w3.org/2001/XMLSchema#string"/>
</owl:AnnotationProperty>

<!-- 第 692 行 -->
<owl:DatatypeProperty rdf:about="http://OntoTCM.org.cn/ontologies/TCM_TO/ICD11ID_data">
    <rdfs:domain rdf:resource="http://OntoTCM.org.cn/ontologies/TCM_TO_0000031"/>
</owl:DatatypeProperty>
```

该属性在本体中被断言约 3,230 次（`ICD11ID_data` 字符串全文件出现 6,467 次 ≈ 2×3,230 + 声明与注释），**每一次使用都被 OWL API 计为一次 IllegalPunning**，故得 3,235。

全库扫描确认：**这是唯一的双重声明实体**，且**不存在 Class ∩ NamedIndividual 的 punning**（0 个实体同时被声明为类与个体）——论文中关于 1.9.9「punning-free modelling」的表述在类/个体层面仍然成立。

### 这不是新引入的回归

| 版本 | IllegalPunning | 说明 |
|---|---|---|
| 1.9.9 | 3,248 | 论文称此版已消除 punning |
| 1.9.12 | 3,248 | 持平 |
| 1.9.15 | 3,240 | 类合并后略降 |
| **1.9.16** | **3,235** | **持续下降** |

### 修复验证（已实测）

删除第 692–694 行的 `owl:DatatypeProperty` 声明块后（`_candidate_fix_ICD11ID_data.owl`）：

| 指标 | 1.9.16 | 修复后 |
|---|---|---|
| owl2_dl | false | **true** |
| owl2dl_profile_violation | {IllegalPunning: 3,235} | **{}（清零）** |
| owl2_el | false | false（EL profile 本就 restrictive，非缺陷） |
| logical_axiom_count | 9,311 | 9,310（**仅少 1 条**，即该声明本身） |

### 对论文表述的影响

| 论断 | 影响 |
|---|---|
| ELK 一致性通过 | **证据本就偏弱**：`owl2_el = false`，ELK 会静默忽略其无法处理的公理。论文现有措辞「ELK completes full consistency checking of **the OWL EL fragment**」是准确的，应保持这个限定。 |
| HermiT 全量分类 exit 0 | 结论仍成立，但**"由完备性 ⇒ 结论决定性"这一论证在严格意义上打了折扣**——OWL 2 DL 的完备性保证形式上适用于 OWL 2 DL 本体，而当前本体因这 1 处双重声明不在此列。删掉该声明即可让论证无懈可击。 |
| JFact 交叉复核未完赛 | 不受影响。 |

### 建议

修复后本体成为严格 OWL 2 DL，HermiT 的完备性论证才真正站得住；同时可勾掉报告 §23 剩余待办 ③「`ICD11ID_data` 双重声明」。

代价：改动后版本号应升为 1.9.17，HermiT 需重跑约 11.5 h 才能对**新版本**下一致性结论（逻辑上删公理不引入不一致，但论文宜以实测为准）。
