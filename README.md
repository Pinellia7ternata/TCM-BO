# TCM-BO: Traditional Chinese Medicine Body-structure Ontology

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)
[![OWL 2 DL](https://img.shields.io/badge/OWL%202%20DL-verified-brightgreen.svg)](validation/measure_1917.json)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22638643.svg)](https://doi.org/10.5281/zenodo.22638643)

**TCM-BO** is a bilingual (Chinese–English) OWL 2 DL ontology of traditional Chinese medicine (TCM) body structures, systematically aligned with **ICD-11**, **FMA** and **SNOMED CT**. It formalises TCM-specific structural relations that have no biomedical analogue (e.g. 开窍于 *opens into*, 相表里 *exterior–interior pairing*, 在体合 *body-tissue correspondence*, 志藏于 *emotion stored in*), supplies an auditable cross-terminology mapping layer, and documents a reproducible quality-control and mapping-audit methodology.

- **Ontology IRI:** `http://OntoTCM.org.cn/ontologies/TCM_TO`
- **Current release:** `1.9.17` (2026-09-03) — strict OWL 2 DL, zero profile violations
- **Archive version:** v1.1 (2026-09-08)
- **Repository:** https://github.com/Pinellia7ternata/TCM-BO

## Logical consistency (verified 2026-09-03/04)

- **HermiT** (sound & complete for OWL 2 DL / SROIQ(D)): full classification, exit code 0, 18 h 54 m 52 s wall-clock, no inconsistency — **decisive verdict**;
- **ELK** (OWL 2 EL): pass in 7 s (independent necessary condition);
- **JFact**: attempted four times (releases 1.9.16/1.9.17); all runs were terminated by the host environment before completion — reported as a verification-infrastructure limitation, not as evidence of a defect.

An earlier JFact-only inconsistency in release 1.9.7 was traced to OWL 1-style
punning conflation (four class IRIs also used as individuals: spleen, pericardial
cavity, cardia, perineum). The minimal reproduction module is archived at
`validation/qc_mini_mod.ofn` (27 axioms, 14 logical axioms): inconsistent under
JFact, consistent under HermiT and ELK. Release 1.9.9 eliminated the root cause
by splitting the four punned IRIs.

Raw logs (`validation/*_verdict.log`), ROBOT `measure` outputs
(`validation/measure_1916.json`, `validation/measure_1917.json`) and the full
evidence packs (`validation/推理机终判证据包_*.md`) ship with this archive.

## Expert review data

`expert_review/` holds the de-identified double-blind mapping-review records and a
script that recomputes the reported inter-rater agreement:

```bash
pip install openpyxl
python expert_review/compute_kappa.py
# kappa = 0.612 (95% CI 0.521-0.702); linearly weighted kappa = 0.676 (0.585-0.767)
# observed agreement 81.8% (260/318); 58 discordant pairs
```

See [`expert_review/README.md`](expert_review/README.md) for the de-identification
statement and the list of review workbooks deliberately not published.

## Reproduce the metrics

```bash
python scripts/metrics_1917.py        # per-IRI aggregated content statistics
python scripts/qc_verify_1916.py      # static QC: type conflicts / asymmetry / sameAs
python scripts/make_figures.py        # figure set
python expert_review/compute_kappa.py # inter-rater agreement statistics
```

Requires Python ≥ 3.8 (`openpyxl` for `compute_kappa.py`). Reasoner verdicts
require [ROBOT](https://robot.obolibrary.org/) 1.9.7 and a Java runtime.
